# תפילות לב – ווידג'ט אנדרואיד

ווידג'ט שמציג על מסך הבית את **התפילה הבאה** בבית המדרש של מכון לב, עם המיקום שלה והתפילה שאחריה.
לחיצה על הווידג'ט פותחת מסך עם **כל תפילות היום** והמיקומים שלהן. התפילה הבאה מודגשת, ואלה שכבר עברו מעומעמות.

הנתונים נמשכים מ-https://midrash.jct.ac.il/זמני-היום (מהבלוק `prayTimes` בדף).

## איך זה עובד
- הזמנים יורדים פעם ביום ונשמרים בטלפון, כך שגם בלי אינטרנט רואים את הזמנים.
- כשתפילה מתחילה מופיע "התחילה עכשיו", ו-5 דקות אחרי ההתחלה הווידג'ט עובר לבאה בתור (אפשר לשנות ב-`GRACE_MINUTES`). לא צריך אינטרנט בשביל זה, ולא צריך הרשאת "התראות מדויקות".
- אחרי התפילה האחרונה מוצגת התפילה הראשונה של מחר. ב-00:05 הזמנים יורדים מחדש.
- גיבוי: אנדרואיד מרענן את הווידג'ט כל 30 דקות.
- יש מצב כהה, ותצוגה מימין לשמאל.

## בנייה – דרך א': GitHub (בלי להתקין כלום)
1. צור repository חדש ב-GitHub (אפשר פרטי) והעלה אליו את כל התיקייה, כולל `.github` ו-`gradlew`.
   ```bash
   cd LevPrayers
   git init && git add . && git commit -m "Lev prayers widget"
   git branch -M main
   git remote add origin https://github.com/<user>/LevPrayers.git
   git push -u origin main
   ```
2. היכנס ללשונית **Actions**. הבנייה מתחילה לבד ולוקחת 3–5 דקות.
3. כשהיא מסתיימת (✓ ירוק), היכנס לריצה והורד את **LevPrayers-apk** מתחתית העמוד. זה קובץ zip ובתוכו ה-APK.

## בנייה – דרך ב': Android Studio
File → Open → בוחרים את תיקיית `LevPrayers`, מחכים לסנכרון של Gradle, מחברים את הטלפון ולוחצים ▶ Run.

## התקנה בטלפון
1. מעבירים את ה-APK לטלפון ופותחים אותו. בפעם הראשונה צריך לאשר "התקנה ממקורות לא ידועים".
2. פותחים את האפליקציה "תפילות לב" פעם אחת כדי שהזמנים ייטענו.
3. לוחצים לחיצה ארוכה על מסך הבית ← ווידג'טים ← "תפילות לב" ← גוררים למסך.

> כל הבניות חתומות באותו מפתח (`app/lev-debug.keystore`), אז גרסה חדשה מתעדכנת מעל הישנה בלי להסיר.
> זה מפתח לשימוש אישי בלבד. אל תשתמש בו לפרסום ב-Play Store.

## אם האתר ישנה מבנה
כל הפענוח נמצא ב-`PrayerRepository.parse()`. הוא מחפש `class="... prayTimes"` ואז זוגות של `<dt>שם</dt><dd>HH:MM</dd>`.
המיקום נלקח מהחלק שאחרי " - " כשהוא מתחיל ב-"ב" ("מנחה - בבית המדרש" ← "בית המדרש").
